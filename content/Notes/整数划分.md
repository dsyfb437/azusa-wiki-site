# 整数划分

把整数 $n$ 拆成若干个正整数，调换顺序算同一种。这类写法称为整数划分。例如 $4=3+1=1+3$，后两种写法表示同一个划分。

## 按部件计数

设 `ways[0] = 1`，其余为 $0$。外层每次引入一种可用的部件 $x$，内层枚举总和。每个划分在其最大部件出现的那一轮被计入。部件可重复时正序更新，互不相同时倒序更新。

```python
def partitions(n, distinct=False):
    ways = [1] + [0] * n
    for part in range(1, n + 1):
        totals = range(n, part - 1, -1) if distinct else range(part, n + 1)
        for total in totals:
            ways[total] += ways[total - part]
    return ways[n]
```

$n=5$ 有 $7$ 种划分，其中部件互异的只有 $5$、$4+1$、$3+2$，共 $3$ 种。如果把总和放外层，每次选最后一项，同一组部件的不同排列就会分别计数。计数题还要按题意决定使用大整数或取模。

## 与生成函数的联系

把加入新部件前、总和为 $s$ 的方案数写成 $a_s$。若重量为 $w$ 的新部件至多选一次，就把多项式 $\sum_s a_s x^s$ 乘上 $1+x^w$，其中 $x^n$ 的系数是更新后总和为 $n$ 的方案数。[[生成函数]]也用这个表示区分「至多选一次」和「可以重复选」。

把部件视为物品、总和视为容量，此处两种更新方向对应[[背包问题]]中的物品使用次数。

## 出处

计数条件取自《整数划分系列》第 2、11 张。划分函数 $p(n)$ 及其生成函数见 [NIST DLMF §27.14 · Unrestricted Partitions](https://dlmf.nist.gov/27.14)。
