# 无向欧拉迹

<span id="无向图的一笔画判定"></span>欧拉迹是恰好经过每条边一次的迹，可以多次经过同一顶点。起点和终点重合时称为欧拉回路。对含边的有限无向图，是否存在欧拉迹由有边部分的连通性和顶点度数的奇偶决定。

要把一幅图一笔画完，每一条线都只经过一次，交点却可以反复经过。将允许换方向的交点或端点记为顶点，两点间的一条线记为边。如果两条线只是立交式地交叉，就各走各的边。

## 两个条件

先从任意一条边的端点出发，只沿边走，看看能否到达所有有边连着的顶点。如果两片图形分离，笔走完第一片就只能抬起来。没有连边的孤立点不参与判定。以下约定至少有一条边，图无向，允许重边和自环。

再数每个点的度，即有多少个边端接在这里，一条自环贡献 2。走到一个中间点，要沿一条边进来再沿另一条边出去，边端总是成对出现。

| 奇数度顶点 | 有边部分连通时的结论 |
| --- | --- |
| 0 个 | 可以从任一非孤立点出发并回到起点，得到欧拉回路 |
| 2 个 | 可以从其中一个奇点出发，到另一个奇点结束，得到开放的欧拉迹 |
| 超过 2 个 | 一笔画不完 |

奇点数总是偶数，因为全部顶点的度数之和等于边数的两倍。单看奇点仍然不够。两个互不相连的三角形上，六个顶点全是偶数度，笔却跨不过两个三角形之间的空白。

## 为什么满足条件就一定能画

所有点为偶数度时，沿还没使用的边一直走。在起点以外的点，每次抵达都消耗一条入边，停下前总还有一条出边可用。因此一段走法最终在起点闭合。如果还有边没走，由连通性，当前闭合路线中至少有一点挨着一条未使用的边。从该点再走一个闭合小圈，把它插回原路线。反复拼接，直到所有边都被使用。

恰有两个奇点时，在两者之间临时加一条有标记的边，所有顶点便都成了偶数度。在求得的回路上去掉这条临时边，余下的就是连接两个奇点的路线。原图中这两点即便已经相邻，仍然可以临时增加一条重边。

例如正方形 $ABCD$ 加一条对角线 $AC$。$A,C$ 的度各为 3，$B,D$ 的度各为 2。一条合法路线是 $A\to B\to C\to D\to A\to C$。从 $B$ 出发无法把这五条边恰好各走一次。

实现连通性检查时，可以忽略孤立点，把每条无向边的两端合并。只要所有非零度顶点最终有同一个代表元，就满足第一个条件；合并操作见[[阈值连通性]]。奇数度顶点仍要另数。
