# 程算 09 文件

## 文件、路径和流

路径用来找到文件，相对路径从进程的当前工作目录解析。`fopen` 返回 `FILE *`，它代表一个 C 流，里面通常维护缓冲、当前位置、结束和错误状态。`stdin`、`stdout`、`stderr` 是预先建立的标准流。文本模式下某些系统会转换换行。字节级复制选二进制模式。

| 模式 | 适用情形 |
| --- | --- |
| `r` / `rb` | 读已有文件，文件缺失时失败 |
| `w` / `wb` | 写文件，成功打开时会截断已有内容，文件缺失时可新建 |
| `a` / `ab` | 追加，写入发生在当时的文件末尾 |
| 加 `+` | 增加读写能力，混合读写时遵守更新流对切换方向的要求 |

`fgetc` 每次返回一个 `int`，成功时能表示任意 `unsigned char`，失败或到结尾时返回 `EOF`。因此保存返回值应使用 `int`。`feof` 只报告流是否已经观察到结束，用 `while (!feof(in))` 作读循环会多进行一次失败的读取。应由读取返回值决定循环何时结束，再用 `ferror` 判断是否出错。

## 从字符复制过渡到块复制

下面把复制职责写成接收两个已经打开的流的函数。它处理读写失败，但流的打开和关闭仍由调用者负责。示例使用临时文件，验证含 `0x00` 和 `0xFF` 的数据能保真复制。

```c
#include <stdio.h>

static int copy_stream(FILE *in, FILE *out) {
    unsigned char block[4096];
    size_t count;
    while ((count = fread(block, 1, sizeof block, in)) != 0) {
        if (fwrite(block, 1, count, out) != count) {
            return 0;
        }
    }
    return !ferror(in);
}

int main(void) {
    const unsigned char sample[] = {0x00, 0xFF, 0x0A};
    FILE *in = tmpfile();
    FILE *out = tmpfile();
    int success = 0;
    if (in != NULL && out != NULL &&
        fwrite(sample, 1, sizeof sample, in) == sizeof sample &&
        fseek(in, 0, SEEK_SET) == 0 && copy_stream(in, out) &&
        fseek(out, 0, SEEK_SET) == 0) {
        int first = fgetc(out);
        int second = fgetc(out);
        int third = fgetc(out);
        int end = fgetc(out);
        success = first == 0 && second == 255 && third == 10 &&
                  end == EOF && !ferror(out);
    }
    if (in != NULL && fclose(in) != 0) {
        success = 0;
    }
    if (out != NULL && fclose(out) != 0) {
        success = 0;
    }
    return success ? 0 : 1;
}
```

实际打开输出文件前要确认不会覆盖正在读取的文件。输出流的错误可能到 `fflush` 或 `fclose` 才报告，最终成功状态要包含关闭结果。格式化文本读写可用 `fprintf` 和 `fscanf`，同样要核对返回值。

## 自检练习

复制空文件、包含 `0xFF` 的文件以及读取权限不足的文件时，应该分别得到什么结果？

> [!tip]- 查看参考答案
> 空文件第一次读取就遇到流末尾，正常得到空输出。二进制模式下，0xFF 应原样写出。输入文件因权限不足而打开失败时，应先报告失败再返回，避免提前以写模式打开并截断目标文件。
