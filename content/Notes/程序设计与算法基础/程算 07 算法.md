# 程算 07 算法

第 7 章《算法》PDF 第 7–8 页给出欧几里得算法及伪代码，第 9–16 页对照五种排序，第 17–24 页比较排序算法的时间开销。

## 先说清正确性，再算成本

写伪代码时说明输入、输出和[[程算 03 流程控制|终止条件]]。对非负整数（至少一个非零），欧几里得算法不断把 `(a, b)` 更新成 `(b, a % b)`。两组数的公因数集合相同，当 b 大于零时，下一轮的第二项严格减小，最后第二项变成 0，第一项就是最大公约数。例如 `(84, 30)` 依次到 `(30, 24)`、`(24, 6)`、`(6, 0)`。

复杂度描述输入变大时的增长趋势。扫描数组求最小值要检查每个元素，时间是 $\Theta(n)$，辅助空间是 $\Theta(1)$。双重循环先算实际执行次数再化简。例如内层在第 `i` 轮运行 `i` 次，累计次数是 $0+1+\cdots+(n-1)$，仍是 $\Theta(n^2)$。

## 排序的结构与取舍

| 算法 | 一轮做什么 | 时间成本与特点 |
| --- | --- | --- |
| 冒泡 | 通过交换相邻逆序元素，把一个极值推到边界 | 常规最坏 $O(n^2)$，加无交换早停后，已排序输入可用 $\Theta(n)$ |
| 选择 | 从未排序区找最小值，放到下一个位置 | 通常比较 $\Theta(n^2)$ 次，交换至多 $O(n)$ 次，常规交换版本不稳定 |
| 插入 | 把当前值插进已经有序的前缀 | 最坏 $O(n^2)$，已有序时 $\Theta(n)$，只移严格较大的值可保持稳定 |
| 归并 | 分半排序，再合并两个有序段 | $\Theta(n\log n)$，数组常用 $O(n)$ 辅助空间，恰当处理相等项可保持稳定 |
| 快速 | 按枢轴划分，再排序各段 | 划分较均衡时 $\Theta(n\log n)$，持续偏斜时 $\Theta(n^2)$。大量重复键可用三路划分 |

稳定性指两个等键元素排序后保留原来的相对次序。比如成绩相同的人要按原报名顺序排，稳定性就是需求的一部分。

```c
#include <stddef.h>
#include <stdio.h>

static void insertion_sort(int values[], size_t count) {
    for (size_t i = 1; i < count; ++i) {
        int current = values[i];
        size_t j = i;
        while (j > 0 && values[j - 1] > current) {
            values[j] = values[j - 1];
            --j;
        }
        values[j] = current;
    }
}

int main(void) {
    int values[] = {5, -2, 5, 1};
    const size_t count = sizeof values / sizeof values[0];
    insertion_sort(values, count);
    for (size_t i = 0; i < count; ++i) {
        printf("%d%s", values[i], i + 1 == count ? "\n" : " ");
    }
    return 0;
}
```

每轮开始前 `[0, i)` 已经有序。循环为 `current` 挪出一个位置，插入后 `[0, i + 1)` 也有序。`j > 0` 放在前面，避免下标是 `size_t` 时让 `j - 1` 回绕。

汉诺塔展示了另一类递归成本。要移 $n$ 个盘，先移走 $n-1$ 个，再移最大的盘，然后把前 $n-1$ 个移到目标柱。因此 $T(n)=2T(n-1)+1$，总移动数为 $2^n-1$。

## 筛素数为什么可以从平方开始？

谭浩强《C 程序设计》第五版参考答案包「第 6 章」第 1 题要求筛出 100 以内的素数。先把 0 和 1 标为非素数，其余数暂作候选。对仍是候选的 $p$，从 $p^2$ 开始，把它的倍数标为合数。更小的倍数 $kp$（$2\le k<p$）至少有一个小于 $p$ 的素因子，前面已经处理过。反过来，每个不超过 100 的合数都有一个不超过 10 的素因子，因此只需以 2、3、5、7 四个素数做筛除。验证时检查 1、2、49、97、100，分别覆盖非素数起点、最小素数、平方数、靠近上界的素数和上界自身。

课程例程 `P7/P71Sort.c` 的归并函数用了严格小于比较。若左右子序列各有一个键为 3 的记录，平局时先取右边，会颠倒相等元素的原顺序。要求稳定排序时应优先取左边。这一性质要用“键相同、标识不同”的记录检查，只看一串排好的整数无法发现差异。

## 自检练习

手推插入排序的前三轮，并构造一种会让固定选首元素为枢轴的快速排序持续偏斜的输入。

> [!tip]- 查看参考答案
> 对示例数组，三轮结束依次得到 [-2, 5, 5, 1]、[-2, 5, 5, 1]、[-2, 1, 5, 5]。第二轮遇到相等的 5，原有的 5 留在前面。在常见的首元素枢轴二路划分中，严格递增的输入会反复选到最小值，留下长度只少一的子问题。
