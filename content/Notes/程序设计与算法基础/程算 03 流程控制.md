# 程算 03 流程控制

## 怎样选分支和循环

- 条件是范围或复合逻辑时用 `if`。互斥条件组成 `if` / `else if`，用题目的边界值检查先后次序。
- 检查同一个整数或枚举值的离散选项时用 `switch`。一个分支执行到末尾后会继续执行后面的分支，直到遇到 `break` 或离开 `switch`。
- 已知迭代次数或下标范围时用 `for`，循环前先判断条件时用 `while`，至少执行一次再检查时用 `do ... while`。`continue` 会结束当前轮，在 `for` 中仍会执行更新表达式。
- `break` 只离开最内层循环或 `switch`。需要从整个搜索提前退出时，可以把搜索写进函数，在找到结果时直接 `return`。

写流程图时，先把每个判断框翻译成一个可以验证的布尔条件，再看哪一条回边构成循环。顺序、选择和循环已经能表达本章的大多数练习。嵌套过深时，把子问题拆进函数，或者用提前返回减少缩进。

## 用循环不变量检查边界

例如统计一个非负整数的十进制位数。每轮先剥掉末位，再增加计数。每轮结束后，`digits` 等于已剥掉的位数，`value` 保存剩下的高位。`0` 约定为一位，所以至少要执行一次。

```c
#include <stdio.h>

int main(void) {
    unsigned value = 1000;
    unsigned digits = 0;
    do {
        value /= 10;
        ++digits;
    } while (value != 0);
    printf("%u\n", digits);
    return 0;
}
```

数组循环常用半开区间 `[0, n)`。上界写 `i < n` 前先问自己 `n` 表示长度还是最后一个下标。`n == 0`、`n == 1` 和最后一次迭代是最值得手推的三个情况。

## 自检练习

把上面的 `do ... while` 换成 `while`，输入 `0` 时计数会怎样？

> [!tip]- 查看参考答案
> 若把条件移到循环入口且保留初值 digits = 0，输入 0 会直接跳过循环，结果是 0 位。用 0、9、10 三个数测试，就能同时覆盖零值和位数第一次变化的边界。
