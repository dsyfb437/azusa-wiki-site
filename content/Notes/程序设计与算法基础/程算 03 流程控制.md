# 程算 03 流程控制

## 怎样选分支和循环

- 条件是范围或复合逻辑时用 `if`。互斥条件组成 `if` / `else if`，用题目的边界值检查先后次序。
- 检查同一个整数或枚举值的离散选项时用 `switch`。一个分支执行到末尾后会继续执行后面的分支，直到遇到 `break` 或离开 `switch`。
- 已知迭代次数或下标范围时用 `for`，循环前先判断条件时用 `while`，至少执行一次再检查时用 `do ... while`。`continue` 会结束当前轮，在 `for` 中仍会执行更新表达式。
- `break` 只离开最内层循环或 `switch`。需要从整个搜索提前退出时，可以把搜索写进函数，在找到结果时直接 `return`。

写流程图时，先把每个判断框翻译成一个可以验证的布尔条件，再看哪一条回边构成循环。顺序、选择和循环已经能表达本章的大多数练习。嵌套过深时，把子问题拆进[[程算 04 函数|有单独输入和返回值的函数]]，或者用提前返回减少缩进。

## 用循环不变量检查边界

从 `1000` 的末尾剥掉一个十进制位，剩下 `100`。再剥就剩 `10`、`1`、`0`。每剥一次便增加一次计数，等高位全部剥完，计数就是原数的位数。

可以用两个变量来记这件事。每轮结束时，`digits` 是已剥掉的位数，`value` 是尚未处理的高位。这个每轮都成立的陈述叫**循环不变量**。剩下一个边界要选：题目把输入 `0` 算作一位，所以即使初值就是 `0`，也要让循环体运行一次。

```c
#include <stdio.h>

int main(void) {
    unsigned value = 1000;
    unsigned digits = 0;
    do {
        value /= 10;
        ++digits;
    } while (value != 0);
    printf("%u\n", digits);
    return 0;
}
```

运行上面的程序会输出 `4`。再把初值换成 `10` 手推：第一次循环后是 `(value, digits) = (1, 1)`，判断还要继续；第二次是 `(0, 2)`，此刻退出。如果刚把 `value` 除到 0 就直接退出，来不及执行最后一次计数，结果就会少一位。

同样的检查也可以用在数组上。若 `n` 是长度，已处理的部分可以写作 `[0, i)`，循环在 `i == n` 时停止。空数组一轮不进；长度为 1 时只处理 `i == 0`。这两个输入经常就能暴露把 `i < n` 写成 `i <= n` 的错误。

[[程算 07 算法|欧几里得算法]]也可以这样检查：每轮取余保持公因数集合，第二个操作数则严格减小到零。这两个观察分别解释了结果为什么正确、循环为什么会结束。

## 用四个年份走一遍分支

谭浩强《C 程序设计》（第五版）书页 24 图 2.10 用流程图逐年判断闰年。从能被 4 整除的年份里去掉整百年，再把能被 400 整除的年份算回来，条件可以写成 `year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)`。测试时选 1900、2000、2024、2023，各穿过一种不同的判断路径，结果依次为平、闰、闰、平。

课程例程 `P3/P3bContinue.c` 让 `c` 从 1 取到 5，逐次计算整数商 `100 / (4 - c)`。当 `c == 4` 时必须在求商前跳过这一轮；`for` 的更新仍会执行，所以接下来还会输出 `c == 5` 时的 −100。若把 `continue` 错写成 `break`，最后一个结果会消失。
