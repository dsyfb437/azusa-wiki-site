# 程算 02 C 语言基础

## 从源文件到可执行文件

预处理展开头文件和宏，编译分析 C 源程序，汇编生成目标文件，链接把目标文件和所需库组合起来。一次 `gcc main.c -o main` 会驱动这些步骤。语法、类型错误常在编译时报出。函数声明能找到而函数实现没有参与链接时，通常在链接阶段才出现 `undefined reference`。

## 类型、表达式和输入输出

| 易混写法 | 正确理解 |
| --- | --- |
| `'A'` 与 `"A"` | 前者是字符常量，后者是带结尾 `\0` 的字符串字面量 |
| `5 / 2` 与 `5 / 2.0` | 前者先做整数除法得到 `2`，后者得到 `2.5` |
| `double x = a / b` | 若 `a`、`b` 都是整型，赋值之前已经截去了小数部分 |
| `=` 与 `==` | 分别表示赋值和相等比较。`if (x = 0)` 会先改写 `x` |
| `&&` 与按位 `&` | `&&` 在左侧为假时跳过右侧，`&` 计算两个操作数的按位结果 |

`int`、`long` 等类型的位宽由实现决定。需要固定宽度时可查看 `<stdint.h>` 中的类型。无符号算术按其范围回绕，C17 的有符号溢出是未定义行为。把负的有符号数与无符号数混在一起比较，也可能发生意外转换。只在业务确实需要时混用两类整数。

`scanf` 需要传入与格式匹配的地址，然后检查它成功赋值了几项。典型的区别是 `scanf("%f", &f)` 读取 `float`，`scanf("%lf", &d)` 读取 `double`。`printf` 的可变参数有提升规则，输出这两类浮点值通常都写 `%f`。交互程序如果需要检查整行是否是合法数字，可以先用 `fgets` 读整行，再用 `strtol` 或 `strtod` 检查结束指针和范围。

```c
#include <stdio.h>

int main(void) {
    int seconds;
    if (scanf("%d", &seconds) != 1 || seconds < 0) {
        fputs("expected a non-negative integer\n", stderr);
        return 1;
    }
    printf("%d:%02d\n", seconds / 60, seconds % 60);
    return 0;
}
```

输入 `125` 得到 `2:05`。`scanf` 没能读到整数时，`||` 的短路规则阻止右侧读取未赋值的 `seconds`。这个小程序只处理有效范围内、位于输入开头的整数，整行格式校验可用上面的分行解析办法补上。

## 自检练习

`(double)(5 / 2)` 与 `(double)5 / 2` 各得到什么？

> [!tip]- 查看参考答案
> 先做括号内的整数除法，5 / 2 得 2，再转成 double 得 2.0。把 5 先转成 double 时，另一个操作数也转换为 double，除法结果是 2.5。
