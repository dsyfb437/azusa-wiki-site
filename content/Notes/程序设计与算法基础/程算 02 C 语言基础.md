# 程算 02 C 语言基础

## 从源文件到可执行文件

写下 `printf("%d\n", 5 / 2);`，在终端看到 `2`，中间至少有两个值得区分的时刻。编译这一行时，编译器从 `<stdio.h>` 看到 `printf` 的声明，知道怎样产生一次调用。要得到可以运行的程序，还需要链接到库中的实现。声明只告诉调用者怎样用它。

一次 `gcc main.c -o main` 会驱动整个过程。先预处理头文件与宏，再将 C 源代码编译、汇编成目标文件，最后[[程算 10 多文件程序|链接各个目标文件与所需的库]]。遇到少写括号一类语法错误，先检查 C 源码；若能生成目标文件，最后却显示 `undefined reference`，可以检查提供该函数定义的文件是否参加了链接。

## 类型、表达式和输入输出

计算 `5 / 2` 时，除号先取得两个整型操作数，算出的结果已经是整数 `2`。把它赋给 `double`，只会得到 `2.0`。要留下半个单位，得在做除法前把一个操作数写成 `2.0` 或转换成浮点数。读下面这些写法时，可以先遮住右栏，自己按「先求哪一步的值」走一遍。

| 易混写法 | 正确理解 |
| --- | --- |
| `'A'` 与 `"A"` | 前者是字符常量，后者是带结尾 `\0` 的字符串字面量 |
| `5 / 2` 与 `5 / 2.0` | 前者先做整数除法得到 `2`，后者得到 `2.5` |
| `double x = a / b` | 若 `a`、`b` 都是整型，赋值之前已经截去了小数部分 |
| `=` 与 `==` | 分别表示赋值和相等比较。`if (x = 0)` 会先改写 `x` |
| `&&` 与按位 `&` | `&&` 在左侧为假时跳过右侧，`&` 计算两个操作数的按位结果 |

`int`、`long` 等类型的位宽由实现决定。同一个[[程算 01 计算机原理|位模式]]由不同类型解释，数值可能不同。需要固定宽度时可查看 `<stdint.h>` 中的类型。无符号算术按其范围回绕，C17 的有符号溢出是未定义行为。把负的有符号数与无符号数混在一起比较，也可能发生意外转换。只在业务确实需要时混用两类整数。

`scanf` 需要传入与格式匹配的地址，然后检查它成功赋值了几项。典型的区别是 `scanf("%f", &f)` 读取 `float`，`scanf("%lf", &d)` 读取 `double`。`printf` 的可变参数有提升规则，输出这两类浮点值通常都写 `%f`。交互程序如果需要检查整行是否是合法数字，可以先用 `fgets` 读整行，再用 `strtol` 或 `strtod` 检查结束指针和范围。

```c
#include <stdio.h>

int main(void) {
    int seconds;
    if (scanf("%d", &seconds) != 1 || seconds < 0) {
        fputs("expected a non-negative integer\n", stderr);
        return 1;
    }
    printf("%d:%02d\n", seconds / 60, seconds % 60);
    return 0;
}
```

输入 `125` 得到 `2:05`。`scanf` 没能读到整数时，`||` 的短路规则阻止右侧读取未赋值的 `seconds`。这个小程序只处理有效范围内、位于输入开头的整数，整行格式校验可用上面的分行解析办法补上。

## 用输入本身验算格式串

为什么读 `2/5` 可以用 `scanf("%d/%d", &num, &den)`？第一个 `%d` 吃掉 `2`，格式串接着要求输入中出现一个斜线，第二个 `%d` 才负责读 `5`。返回值数的是成功赋值的项，斜线匹配成功不会多算一项。

把输入换成 `2,5`。第一个整数已写入，要求的斜线却碰到了逗号，返回值为 1，分母还不能用。再换成 `2/0`，这次返回 2，格式正确，但分母必须另做非零检查。若题目允许斜线前有空白，可在格式串的斜线前放一个空格。旧课件《C语言入门》第 34–37 页与《C 语言程序设计基础（编程指导版）》§2.6.2–2.6.3，书页 27–29，分别给出了输入匹配和分数加法例。

`5 / 9 * (f - 32)` 中前两个操作数都是整数，第一步得到零。即使结果存入 `double`，也恢复不了已舍去的小数。用 `(5.0 / 9.0) * (f - 32.0)`，再以华氏 32、212 度分别核对摄氏 0、100 度。旧课件《运算符与表达式》第 15 页与 `P2/P29Cast.c` 都适合练习判断“哪一步发生类型转换”。

谭浩强《C 程序设计》第四版课后答案第 3 章第 5 题（答案 PDF 第 4 页）把整数、浮点数和字符混合读入。做这类题时可在整数后按一次回车，再读一个 `%c`，观察程序会把刚才的换行读走；若题意要求下一个非空白字符，可用 `" %c"` 跳过前导空白。遇到空格或换行本身有意义的题目，则保留 `%c` 原样读取。

旧课件《数据类型》第 34–50 页列有整型范围和溢出例。写可移植程序时可用 `<limits.h>` 查询本机上限。有符号 `int` 的加法结果超出可表示范围会产生未定义行为；`unsigned int` 加法按模 `UINT_MAX + 1` 回绕，这里的模数是数学意义上的值。

**课件出处**　第 2 章《基础知识》 PDF 第 2–4 页展示第一个 C 程序从源文件到执行的过程，第 6–12 页比较基本类型与字符常量。

## 自检练习

`(double)(5 / 2)` 与 `(double)5 / 2` 各得到什么？

> [!tip]- 查看参考答案
> 先做括号内的整数除法，5 / 2 得 2，再转成 double 得 2.0。把 5 先转成 double 时，另一个操作数也转换为 double，除法结果是 2.5。
