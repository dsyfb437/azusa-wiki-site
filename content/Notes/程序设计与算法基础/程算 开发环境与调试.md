# 程算 开发环境与调试

- 在 VS Code 打开项目文件夹，在终端用 `gcc --version` 确认编译器可用。编辑器能显示语法高亮，不代表终端已经能找到编译器。
- 日常编译可用 `gcc -std=c17 -Wall -Wextra -Wpedantic -g main.c -o main`。`-g` 保留调试信息，警告有时能提前指出格式串、类型或未使用变量的问题。
- 遇到逻辑错误，先保留最小失败输入。循环出错就跟踪下标与不变量，数组或指针出错就看对象范围和存储期，计算器出错就依次检查 token、后缀序列和数值栈。
- 在调试器里区分逐过程、逐语句和跳出当前函数。只在关键范围设断点，查看同一变量在调用前后是否仍指向有效对象。多文件项目注意构建配置包含所有需要链接的 `.c` 文件。

## 用一个失败输入练习断点

假设计算器把 `10 - 3` 算成了 `-7`。先在分词后看三个 token，再在求值函数入口确认后缀序列为 `10 3 -`。若两处都正确，在减法分支弹栈前暂停。栈顶应为 3，下面是 10。单步执行两次弹栈，观察 3 是否被保存为右操作数。修正后再试 `8 / 2`，检查另一个与顺序有关的运算。
