# 程算 10 多文件程序

## 头文件、翻译单元和链接

头文件放调用者需要知道的类型、常量和函数声明。源文件放函数定义与模块内部状态。一个 `.c` 文件连同预处理后包含进来的内容构成一个翻译单元。每个翻译单元分别得到目标文件，链接器再解析跨文件的符号引用。

| 写法 | 用途 |
| --- | --- |
| `#include <stdio.h>` | 引入标准库接口。自定义头文件通常用双引号形式包含 |
| `#ifndef` / `#define` / `#endif` | 保护头文件，避免同一翻译单元重复处理其中的声明和类型 |
| `#if` / `#ifdef` | 按构建条件选择代码，例如控制调试输出 |
| 源文件中的 `static` 函数 | 将帮助函数限制在本翻译单元 |
| 头文件里的 `extern int counter;` | 声明外部对象。在确有共享状态需求时，只在一个源文件里提供相应定义 |

下面三个小文件演示接口怎样独立于输入输出。计算器里可以用同样的方法把运算规则、分词和界面分开。

`calc.h`

```c
#ifndef CALC_H
#define CALC_H

/* On failure, the caller's result is unchanged. */
int calc_divide(double left, double right, double *result);

#endif
```

`calc.c`

```c
#include "calc.h"

int calc_divide(double left, double right, double *result) {
    if (right == 0.0) {
        return 0;
    }
    *result = left / right;
    return 1;
}
```

`main.c`

```c
#include <stdio.h>
#include "calc.h"

int main(void) {
    double result = -1.0;
    if (calc_divide(7.0, 0.0, &result) || result != -1.0 ||
        !calc_divide(7.0, 2.0, &result)) {
        return 1;
    }
    printf("%.1f\n", result);
    return 0;
}
```

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic -c calc.c
gcc -std=c17 -Wall -Wextra -Wpedantic -c main.c
gcc main.o calc.o -o calc-demo
```

若漏掉最后一步的 `calc.o`，`main.c` 仍能编译，因为它已看到了声明，但最终链接不了。若把普通函数定义放进头文件并被两个 `.c` 文件包含，则可能看到 `multiple definition`。项目变大后，可用 Makefile 记录哪些目标文件依赖某个头文件，修改接口时只重编受影响的文件。

## 高内聚与松耦合落到代码上

一个模块应围绕一项职责组织。解析器从 token 构造正确的运算顺序，求值器按该顺序计算，界面决定怎样显示结果和错误。改变提示语时不应修改算术规则。改变栈的内部表示时，调用方也不应受到影响。这两条可以用来判断文件和函数的拆分是否合适。

## 用中间产物定位一次构建失败

旧课件《程序设计引论》第 35–42 页以一个打印字符串的小程序追踪构建过程。以 GCC 为例，`gcc -E hello.c -o hello.i` 可检查头文件和宏展开；`gcc -S hello.c -o hello.s` 可看这一份源码怎样变成汇编；`gcc -c hello.c -o hello.o` 得到可重定位目标文件。若另一个翻译单元提供函数实现，最后才将两个目标文件一同链接。

例如 `main.c` 引用了头文件中已声明的 `calc_eval`，两个源文件都能单独编译。若最终命令漏掉 `calc.o`，通常到链接阶段才会报告缺少该符号。此时首先对照参与链接的目标文件列表；重复包含头文件不会补出函数定义。

## 自检练习

把 `calc.c` 从链接命令里移走，故障发生在哪个阶段？如果只改变 `calc.h` 的函数签名，该重新编译哪些文件？

> [!tip]- 查看参考答案
> 各源文件仍能生成目标文件。缺少 calc.o 时，链接器找不到 calc_divide 的定义。改变头文件中的签名后，要重新编译直接或间接包含该头文件的翻译单元，再重新链接。本例是 calc.c 和 main.c。
