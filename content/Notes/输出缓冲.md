# 输出缓冲

C++ 输出流可以先把字符存入缓冲区，再交给底层输出目的地。输出换行符 `'\n'` 表示这一行已经结束；显式刷新则要求流立即把已缓冲的数据交给底层。交互题中，程序可能要等对方读到查询才会收到下一条输入。

## 输出一行数字

输出一行 $n$ 个整数时，可以把分隔符放在数字前，只在第二个数起输出空格，最后单独输出换行。这也覆盖 $n=0$ 时输出空行的情况。

```cpp
for (int i = 0; i < n; ++i) {
    if (i > 0) std::cout << ' ';
    std::cout << a[i];
}
std::cout << '\n';
```

旧笔记中的 `" \n"[i == n]` 依靠布尔值充当下标，`false` 取空格，`true` 取换行，写法假定循环从 $1$ 到 $n$。

## 何时刷新

普通批量输出用 `'\n'` 即可。`std::endl` 同时换行并刷新流，放在大循环里会反复强制刷新。交互题若要在等待回复前送出查询，应按协议及时刷新，例如 `std::cout << '\n' << std::flush;`。

调试程序时，可以先用[[竞赛程序调试|固定输入]]复现计算过程，再检查输出的数值、分隔符和刷新时机。

## 出处

分隔符的示例来自旧题记《输出换行效率》《输出换行 trick》。`std::endl` 和 `std::flush` 的操作由 [C++ 标准草案 · Standard basic_ostream manipulators](https://eel.is/c++draft/ostream.manip) 定义。
