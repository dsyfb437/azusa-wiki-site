# 背包的状态与更新顺序

一个容量为 $6$ 的背包，现在什么物品都没拿。表格里的 `dp[3]` 应该填 $0$ 吗？先把下标 $3$ 翻译成题目里的话。

- 如果问「总重量**至多**为 $3$，能拿到的最大价值是多少」，空背包就满足条件，答案是 $0$。每个容量都能这样初始化。
- 如果问「总重量**恰好**为 $3$，能拿到的最大价值是多少」，现在没有任何装法。此时只有 `dp[0]` 为零，其余位置都应标成不可达。

两种表都能用来回答一个允许剩余容量的问题。第一种表直接读 `dp[V]`；第二种表要在所有可达的 $j\le V$ 中找最大值。

## 一件物品能用几次

重量 $w>0$、价值 $v$ 的物品只给一件。设 $F_i(j)$ 表示考虑前 $i$ 件、容量至多 $j$ 时的最大价值。$j\ge w$ 时有

$$
F_i(j)=\max\bigl(F_{i-1}(j),\, F_{i-1}(j-w)+v\bigr).
$$

左边的选择是把这一件留在外面，整份容量 $j$ 交给前 $i-1$ 件。右边的选择是先放进它，背包只剩 $j-w$ 的位置，而且不能再放同一件，因而仍得查**上一行**。这里的下标 $i-1$ 决定了后面写循环时要朝哪边走。

把两行压在同一个数组里，哪里还留着「上一行」？拿重量 $3$、价值 $5$ 的物品试一次。仍按「至多」初始化，本轮开始时 `dp[3]` 和 `dp[6]` 都是 $0$。

| 扫描顺序 | 算 `dp[6]` 时读到的 `dp[3]` | 得到的价值 |
| --- | --- | --- |
| 先算 $6$，后算 $3$ | 旧值 $0$，物品还没放过 | $0+5=5$ |
| 先算 $3$，后算 $6$ | 新值 $5$，已经放过一次 | $5+5=10$ |

所以每件只给一个时，从 $V$ 向下扫到 $w$ 就保住了旧值。若同种物品有无穷多个，已经放过一件的状态恰好还能再放，递推右侧改用 $F_i(j-w)$，应当从 $w$ 向上扫。复习时忘了方向，可以只画出 `dp[3]` 和 `dp[6]` 这两个格子重算。

## 计数时，先想什么算同一种方案

把整数 $n$ 拆成若干个正整数，调换顺序算同一种。设 `ways[0] = 1`，其余为 $0$。外层每次引入一种可用的部件 $x$，内层枚举总和。每个划分在其最大部件出现的那一轮被计入。部件可重复时正序更新，互不相同时倒序更新。

```python
def partitions(n, distinct=False):
    ways = [1] + [0] * n
    for part in range(1, n + 1):
        totals = range(n, part - 1, -1) if distinct else range(part, n + 1)
        for total in totals:
            ways[total] += ways[total - part]
    return ways[n]
```

$n=5$ 有 $7$ 种划分，其中部件互异的只有 $5$、$4+1$、$3+2$，共 $3$ 种。如果把总和放外层，每次选最后一项，同一组部件的不同排列就会分别计数。计数题还要按题意决定使用大整数或取模。

把加入新部件前、总和为 $s$ 的方案数写成 $a_s$。若重量为 $w$ 的新部件至多选一次，就把多项式 $\sum_s a_s x^s$ 乘上 $1+x^w$，其中 $x^n$ 的系数是更新后总和为 $n$ 的方案数。[[从多项式系数数方案]]也用这个表示区分「至多选一次」和「可以重复选」。
