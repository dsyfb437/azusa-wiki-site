# 字符串的前缀与重叠匹配

模式串 `aba` 在 `ababa` 中出现两次，起点是 $0$ 和 $2$。第一次匹配结束时，末尾的 `a` 同时是下一次匹配的开头。要找全重叠位置，完整匹配后仍要记住这一段。

| 文本下标 | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| 字符 | a | b | a | b | a |
| 第一次匹配 | a | b | **a** | | |
| 第二次匹配 | | | **a** | b | a |

看下标 $2$ 这一列。我们已经读过这个字符，并且知道它等于模式的第一个字符。下一次只需从文本下标 $3$ 继续看，同时记着「开头的一个字符已经匹配」。若匹配成功就把这个数字加一。

一般要记几个字符？先只看模式串 $P$。截取 $P[0..i]$，找一段既出现在它开头又出现在末尾的相同字符串，长度不能是整段的长度。最长的这种长度就记作 $\pi[i]$。例如 `aba` 的开头和结尾都能取 `a`，故 $\pi[2]=1$，正是表中可以重用的一个字符。若模式本身换成 `ababa`，最后可重用的是 `aba`，完整的前缀数组是 $[0,0,1,2,3]$。

## 失配时为什么可以跳

假设要找 `ababaca`，文本中刚刚读完 `ababa`，紧接着却来了一个 `b`。此刻 $j=5$，原本等的是模式下标 $5$ 的 `c`。这次尝试失败了，但刚才读过的五个字符以 `aba` 结尾，恰好能接作模式的前三个字符。

于是把 $j$ 从 $5$ 调到 $\pi[4]=3$，拿**同一个** `b` 去比较 $P[3]$。这次相等，匹配长度变为 $4$，才读下一个文本字符。代码里的 `while` 正是在找这种接得上的前缀：如果最长候选也接不上，就继续试它的最长真前后缀。文本指针始终向前。

```python
def find_all(text, pattern):
    if not pattern:
        return list(range(len(text) + 1))
    pi = [0] * len(pattern)
    for i in range(1, len(pattern)):
        j = pi[i - 1]
        while j and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j

    starts = []
    j = 0
    for i, ch in enumerate(text):
        while j and ch != pattern[j]:
            j = pi[j - 1]
        if ch == pattern[j]:
            j += 1
        if j == len(pattern):
            starts.append(i - j + 1)
            j = pi[j - 1]
    return starts
```

空模式串在这里约定匹配所有字符间隙，包括首尾。若只统计非空模式的次数，可以直接累加计数。预处理和扫描中，$j$ 每读一个新字符最多增加 $1$，每次回退至少减少 $1$，总回退数受总增长量限制。时间为 $O(|P|+|T|)$，除输出外占 $O(|P|)$ 空间。

当任务是查询若干个完整字符串是否已经出现，直接用集合更合适；有大量共享前缀的词且需要前缀计数时，可用字典树，在节点分开记录经过次数与结束次数。只存固定长度的哈希值会有碰撞，要求严格判等时还需核对原串。

把实现接到 C 字符串上时，文本长度应停在终止空字符之前。匹配位置按字符数组的下标计，表示方法可对照[[程算 06 数组与字符串]]。
