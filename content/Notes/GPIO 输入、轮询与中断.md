# GPIO 输入、轮询与中断

用一个按键切换 LED 状态，先要说清楚哪次动作算一次按键。假设电路约定松开读到高电平、按下读到低电平。读取 GPIO 得到的是此刻的电平，“一次按下”则是电平从稳定的高变成稳定的低。一直按住时，主循环可能读到几千次低电平，只应该翻转一次灯。

## 轮询和中断各看到了什么

轮询是在主循环或定时回调中检查引脚。取一个理想的示意序列，每隔 5 ms 读取一次，读到 `1, 1, 0, 0, 0, 1`。保留上次稳定状态，就能在第一次确认低电平时产生按下事件，后面的低电平表示仍然按住。如果完整的一次按下与松开都发生在两次采样之间，单凭这批采样无法发现它。

外部中断可以在指定的边沿到来时通知处理器。机械触点反弹可能让一次按下产生好几个边沿，换成中断以后仍要去抖。一种做法是中断只登记候选变化，再由定时器取样，确认输入持续稳定后才生成事件。稳定窗口要依据器件特性和响应要求选取。把长延时或整段显示刷新塞进中断处理会增加其他任务的等待时间。

## 怎样区分输入故障和输出故障

先看两组计数：一组数原始电平变化，一组数确认后的按下事件。点击一次，第一组跳好几次、第二组只加一，说明去抖与事件识别起了作用。若第二组也连续增加，先检查状态转换；若第二组正确而灯不动，再检查输出配置、LED 极性和更新灯状态的代码。

PWM 调光是另一个输出实验。假设在每个 $1\,\mathrm{ms}$ 周期中输出高电平 $0.25\,\mathrm{ms}$，则频率为 $1\,\mathrm{kHz}$，高电平占空比为 $25\%$。实际亮度还与点亮极性、电流和人眼响应有关。观察波形时，可把周期和高电平时间分别量出来，避免把频率变化误认为占空比变化。
