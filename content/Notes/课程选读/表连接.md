# 表连接

<span id="联表之后为什么多了几行"></span>

一张借阅表记录「哪天借了哪本书」，一张书目表记录「这本书属于哪一类」。若书目表对每个书号只有一行，就能按书号把类别补到每次借阅上。先约定一行代表什么，再考虑怎么连表。

| 借阅记录 | 书号 |
| --- | --- |
| 甲 | B01 |
| 乙 | B01 |
| 丙 | B02 |

假设书目表把 B01 同时归入「历史」和「文学」，而 B02 还没有登记。先只跟着甲这一条借阅走：用 B01 到右表找，会找到两个符合条件的类别。连接会把两种配对都交出来。再照此处理乙和丙，手工就能预言表会多大。

| 左侧记录 | 能配到的类别 | 内连接留下几行 | 左连接留下几行 |
| --- | --- | ---: | ---: |
| 甲，B01 | 历史、文学 | 2 | 2 |
| 乙，B01 | 历史、文学 | 2 | 2 |
| 丙，B02 | 尚未登记 | 0 | 1（类别为空） |
| 合计 | | 4 | 5 |

数行数时可以逐个书号来。若某个键在左表出现 $m$ 次、右表出现 $n$ 次，内连接会为它生成 $mn$ 行。左连接遇到右侧完全没有匹配时，会为每条左侧记录保留一行。

要解释结果，再问一遍最初的「一行代表什么」。甲借的仍然是一本书，连接后的两行表示这次借阅关联了两个类别。按类别统计时两行都有意义；统计借阅总次数时，得回到借阅记录这个单位。

## 把预期写进代码

下面是一个另外构造的小例子。它要求右表书号唯一，保留每一条借阅，并把未知类别单列。

~~~python
import pandas as pd

loans = pd.DataFrame({"book": ["B01", "B01", "B02"]})
catalog = pd.DataFrame({"book": ["B01"], "topic": ["历史"]})
joined = loans.merge(catalog, on="book", how="left",
                     validate="many_to_one", indicator=True)
counts = joined["topic"].fillna("未登记").value_counts()
~~~

结果为历史 2 次、未登记 1 次。若给右表再添加一条书号 B01 的记录，唯一性检查会报错。可以先查看重复键对应的完整行，决定是录入重复还是一对多关系。直接按书号删重，会把真正不同的类别也删掉。

## 分组和透视的分母

同结构的借阅月表可以按行拼接，再与书目表关联。若每次借阅只归入一个类别，把所有类别的借阅次数相加，应能还原原借阅记录数。若一本书关联了两个类别，这个等式就不能直接用于核对。把月份与类别排在两个方向、比较记录数与不同书号数的方法，见[[数据透视表]]。

同样的问题会出现在[[票房统计|按影片统计票房]]时。一部影片若关联到两个类型，按类型各计一次有其含义；把联表后的所有行再相加，同一部影片的票房就计了两次。
