# 条件命题

<span id="条件命题与量词的否定"></span>

「只有取到偶数才给它贴蓝签」约束的是贴蓝签的数。设 $B(n)$ 表示有蓝签，$E(n)$ 表示是偶数，原话写成 $B(n)\Rightarrow E(n)$。一张没有蓝签的偶数卡片符合规则；一张有蓝签的奇数卡片就足以推翻它。

| $B$ | $E$ | $B\Rightarrow E$ |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 真 |
| 假 | 假 | 真 |

逆否命题 $\neg E\Rightarrow\neg B$ 和原命题等价，两者被同一类卡片反驳。交换前后件得到 $E\Rightarrow B$，它要求给每个偶数贴签，多加了原规则没有规定的义务。

## 先定论域，再写反例

一条规则常常省略开头的「对每一张卡片」。若论域为整盒卡片，「只有偶数才贴蓝签」完整写作 $\forall n\,(B(n)\Rightarrow E(n))$。否定它，必须在盒中找得到一张同时满足 $B(n)$ 与 $\neg E(n)$ 的卡片。若盒里一张蓝签也没有，这条规则仍然成立。

若再问「每个盒子里至少有一张蓝签」，卡片的选取依赖于盒子；空盒也会改变结论。[[量词]]列出了这种嵌套命题的否定与反例。

## 出处

《离散数学期末复习》PDF 第 9–15 页讲命题、联结词和真值表。第 3.2 节（第 36 页起）讲量词，第 3.6 节（第 47 页起）列谓词公式的等价律。蓝签规则为自拟例。
