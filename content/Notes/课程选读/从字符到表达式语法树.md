# 从字符到表达式语法树

输入 `18 - 3 * 4` 时，词法分析器先把相邻的两个数字识别成一个整数，输出记号流 `INT(18), MINUS, INT(3), STAR, INT(4)`。记号可以顺带记录起止位置，例如遇到无法识别的字符时就能指出它在第几列。空白是否跳过、负号是否属于数字，都是语言先约定的规则。

语法分析器接到的已经是一串记号。下面的文法只考虑非负整数、减号、乘号和括号：

~~~text
表达式 = 乘积 { "-" 乘积 }
乘积   = 原子 { "*" 原子 }
原子   = 整数 | "(" 表达式 ")"
~~~

读一个「表达式」时，先让「乘积」读完它负责的部分。乘号会被内层收走，于是整棵树写作 `sub(18, mul(3, 4))`，求值等于 6。输入改为 `(18 - 3) * 4`，括号让内部提前完成一次表达式分析，结果变成 60。重复出现减号时，按从左向右累积已有左子树的方式构造，`18 - 3 - 4` 会得到 `sub(sub(18, 3), 4)`。

## 两类错误落在哪一层

若这个小语言没有字母和井号，输入 `2 # 3` 到井号时，扫描器已经无法产出合法记号。输入 `2 * )` 的每个字符都能分词，但乘号后面应当出现原子，右括号在这个位置放不下，错误出在语法层。输入 `2 3` 也应报错，因此解析入口除了读出一棵树，还要确认已经到达输入末尾。
