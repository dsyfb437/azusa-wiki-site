# 微积分 洛必达法则与不定式

[[微积分课程笔记|返回课程目录]]

原笔记 §2.7，PDF 第 53–55 页。

## 哪些极限能分别求导

对 $\lim f(x)/g(x)$，先确认同一趋近方向下是 $0/0$ 或 $\infty/\infty$ 型。若在去心邻域内 $f,g$ 可导、$g'(x)\ne0$，且 $\lim f'(x)/g'(x)=L$ 存在（可以是单向无穷大），则原极限亦为 $L$。每重复用一次都要重新判断。对有限点 $0/0$ 型，给两个函数在该点补上零，用 [[微积分 微分中值定理|柯西中值定理]]，可把原商表示成某个中间点的导数之比；该点随 $x$ 一起趋于极限点。

**第 54 页例 12 的反例。** 当 $x\to+\infty$，$(x+\cos x)/x=1+\cos x/x\to1$。分子分母的导数之比为 $1-\sin x$，没有极限。此时洛必达法则给不出结论，原极限仍存在。同理 $(x-\sin x)/(x+\sin x)$ 及 $(x-\cos x)/(x+\cos x)$ 同除以 $x$ 后极限都是 $1$。

## $0/0$ 型与 $\infty/\infty$ 型（第 53 页）

| 原题 | 计算 |
| --- | --- |
| 例 1，$\lim_{x\to0}\tan x/x$ | 求导得 $\sec^2x\to1$。 |
| 例 2，$\lim_{x\to1}(x^3-3x+2)/(x^3-x^2-x+1)$ | 分子分母分别为 $(x-1)^2(x+2)$、$(x-1)^2(x+1)$，约分得 $3/2$。 |
| 例 3，$\lim_{x\to+\infty}(\pi/2-\arctan x)/(1/x)$ | 两负号相消，所得 $x^2/(1+x^2)\to1$。 |
| 例 4，$\lim_{x\downarrow0}\ln(\sin ax)/\ln(\sin bx)$，取 $a,b>0$ | 同趋 $-\infty$，导数之比为 $a\cot(ax)/(b\cot(bx))$，由 $u\cot u\to1$ 得 $1$。 |
| 例 5，$\lim_{x\to\pi/2}\tan x/\tan3x$ | 写 $x=\pi/2+h$，变成 $\cot h/\cot3h=\tan3h/\tan h\to3$。两侧均成立。 |
| 例 6，$\lim_{x\to0}(\tan x-x)/(x^2\tan x)$ | 分母可换为 $x^3$。求导一次，变为 $\tan^2x/(3x^2)\to1/3$。 |

例 6 的减法消去了 $\tan x$ 的一次项，所以要保留分子整体。原笔记旁边的三道变式中，$\frac1{x^2}-\frac1{x\tan x}$ 通分后就是例 6，极限 $1/3$；分母换成 $x^2\sin x$，结果仍为 $1/3$；若分子也换成 $\sin x-x$，则求导出现 $\cos x-1\sim-x^2/2$，结果为 $-1/6$。

## 乘积、差与幂（第 54–55 页）

$0\cdot\infty$ 型可把一因子移到分母；$\infty-\infty$ 型先通分或有理化。对于 $y=u(x)^{v(x)}$ 的 $1^\infty,0^0,\infty^0$ 型，在 $u(x)>0$ 的一侧先求 $\lim v(x)\ln u(x)$，最后取指数。

| 原题 | 化简后得到什么 |
| --- | --- |
| 第 54 页例 7，$\lim_{x\to+\infty}e^{-x}x^2$ | 写成 $x^2/e^x$，两次求导后 $2/e^x\to0$。 |
| 例 8，$\lim_{x\to0}(1/\sin x-1/x)$ | 通分为 $(x-\sin x)/(x\sin x)$；分母等价于 $x^2$。一次求导得 $(1-\cos x)/(2x)\to0$。 |
| 例 9，$\lim_{x\downarrow0}x^x$ | $x\ln x=\ln x/(1/x)\to0$，故极限为 $1$。 |
| 例 10，$\lim_{x\to1}x^{1/(1-x)}$ | $\ln x/(1-x)\to-1$，故极限为 $e^{-1}$。 |
| 例 11，$\lim_{x\downarrow0}(\cot x)^{1/\ln x}$ | $\ln(\cot x)/\ln x$ 求导后为 $-x/(\sin x\cos x)\to-1$，结果 $e^{-1}$。 |
| 例 13，$\lim_{x\to0}(1/x-1/(e^x-1))$ | 通分得 $(e^x-1-x)/[x(e^x-1)]$。分母等价于 $x^2$，分子与 $x^2$ 的比求导得 $(e^x-1)/(2x)\to1/2$。 |
| 第 55 页例 14，$\lim_{x\to0}(\cos x)^{1/x^2}$ | $\ln(\cos x)/x^2$ 求导后为 $-\tan x/(2x)\to-1/2$，结果 $e^{-1/2}$。 |
| 例 15，$\lim_{x\downarrow0}x^{\sin x}$ | 对数为 $(\sin x/x)(x\ln x)\to0$，结果 $1$。 |

**第 47 页页边手写题。** 求 $\displaystyle\lim_{x\to0}\left[\frac{(1+x)^{1/x}}{(1+2x)^{1/(2x)}}\right]^{1/x}$。底数趋于 $1$，先取对数，化成 $[2\ln(1+x)-\ln(1+2x)]/(2x^2)$。在 $0$ 附近一次洛必达后约去 $x$，得 $1/[2(1+x)(1+2x)]\to1/2$，所以原极限为 $\sqrt e$。

## 从已知导数组合倒推原函数（第 55 页例 16）

若 $\alpha>0$，$f$ 在充分大的 $x$ 处可导，且 $\alpha f(x)+xf'(x)\to\beta$，证 $f(x)\to\beta/\alpha$。观察 $(x^\alpha f)'=x^{\alpha-1}[\alpha f+xf']$。写 $f=(x^\alpha f)/x^\alpha$，分母趋于 $+\infty$，导数之比趋于 $\beta/\alpha$。这里用的是**分母趋于无穷的推广形式**，无需预先断定分子趋于无穷。其理由：固定充分大的 $A$，对分子分母在 $[A,x]$ 上用柯西中值定理；若导数之比在 $A$ 右侧与目标相差小于 $\varepsilon$，增量比也满足相同估计。除以趋于无穷的分母后，固定端点值的影响消失。

同页练习：若 $f(x)+xf'(x)\ln x\to l$，把 $f$ 写成 $[f(x)\ln x]/\ln x$。分子、分母分别求导再相除，恰好得到题给组合，故 $f(x)\to l$。页中另列 Stolz 定理作为数列极限的自学题。

## 原笔记练习 17–19（第 55 页，解答补写）

**17．** $f$ 在 $0$ 可导，$f(0)=0$。计算 $\lim_{x\to0}f(1-\cos x)/\tan(x^2)$。把原式拆成三因子，

$$
\frac{f(1-\cos x)}{1-\cos x}\cdot\frac{1-\cos x}{x^2}\cdot\frac{x^2}{\tan(x^2)}
\longrightarrow f'(0)\cdot\tfrac12\cdot1.
$$

**18．** $f$ 有连续一阶导数，$f''(0)$ 存在，且 $f(0)=f'(0)=0$。若 $g(x)=f(x)/x$（$x\ne0$），如何补 $g(0)$ 使它连续，并验证 $g'$ 连续？由导数定义补 $g(0)=0$。记 $A=f''(0)$，由导数定义及二阶展开，$f'(x)=Ax+o(x)$，$f(x)=Ax^2/2+o(x^2)$。因此 $g'(0)=\lim f(x)/x^2=A/2$；在 $x\ne0$ 处，$g'(x)=[xf'(x)-f(x)]/x^2\to A/2$。其余点的一阶连续性来自商法则。

**19．** 选 $a,b$ 使 $\lim_{x\to0}(1+a\cos2x+b\cos4x)/x^4$ 有限。常数项和二次项必须为零，即 $1+a+b=0,\ a+4b=0$。得 $a=-4/3,\ b=1/3$。此时分子等于 $\tfrac23(1-\cos2x)^2$，由 $1-\cos2x\sim2x^2$ 得极限 $8/3$。
